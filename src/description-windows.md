Windows: a resize repaints the whole screen from ConPTY, so the output after it carries a redraw. File tools and cwd accept Git Bash /c/... drive paths and report paths as C:/...; other driveless paths such as /tmp name Git Bash locations and are refused (convert them with cygpath -m). Git Bash rewrites arguments that look like POSIX paths (/c, /F, /tmp/x) for native programs; prefix MSYS_NO_PATHCONV=1 or set MSYS2_ARG_CONV_EXCL. Run PowerShell from a script file (pwsh -NoProfile -NonInteractive -File x.ps1) or with -EncodedCommand. loginShell: false skips the profile and starts faster.
